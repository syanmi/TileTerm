# TileTerm

任意のコンソールアプリケーションを画面分割で同時に操作できる、Windows 向けの C# デスクトップターミナルツール。

## コンセプト

[RLogin](https://osdn.net/projects/rlogin/) が持つ「1つのウィンドウを複数のペインに分割し、複数セッションを同時に操作できる」という設計思想を参考にしている。

- 1つのウィンドウを複数のペインに分割し、それぞれに独立したコンソールセッションを表示・操作できる
- 起動する実行ファイル(.exe)と起動引数は「プロファイル」として設定でき、新規セッションを開始する際はそのプロファイルに応じた画面が起動する
- ターミナルツール本体は特定のコンソールアプリの実装に依存せず、設定さえすれば任意のコンソールアプリを同じ仕組みで操作できることを目指す
  - 例: コマンドプロンプト(cmd.exe) / PowerShell / Git Bash / Claude Code CLI (claude) など

## 対象プラットフォーム

- Windows
- C# (.NET) デスクトップアプリケーション

## ステータス

プロジェクト立ち上げ段階。設計・実装はこれから。

## 名前の由来

"Terminal" + "Tile"（画面をタイル状に分割してセッションを配置する機能）から命名。
